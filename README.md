# Construcción de Software I – Informes de práctica

Repositorio con los informes de práctica de Java de la asignatura **Construcción de Software I**
(Facultad de Ingenierías, Ingeniería en software, Tecnológico de Antioquia – Institución Universitaria, Medellín).

**Autor:** Jorge Luis Rentería Diaz

## Contenido

| Carpeta | Descripción |
|---|---|
| `Informe_No1/` | Informe No. 1: variables, tipos de datos, operadores y clase `Math` (PDF). |
| `Informe_No2/` | Informe No. 2: 18 ejercicios de condicionales, switch case, String y excepciones, ciclos, vectores y matrices (Word). |
| `Informe_No2/programas/` | Código fuente de los 18 ejercicios del Informe No. 2 (`Ejercicio01.java` a `Ejercicio18.java`). |

## Cómo ejecutar un programa

Se necesita tener instalado Java 11 o superior. Desde la carpeta `Informe_No2/programas/`:

```bash
java Ejercicio05.java
```

O, compilando primero:

```bash
javac Ejercicio05.java
java Ejercicio05
```

En Visual Studio Code también se puede abrir el archivo y usar el botón **Run** sobre `main`.
